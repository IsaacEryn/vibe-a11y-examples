# vibe-a11y-examples

《바이브 코딩, 접근성까지 부탁해》(가제) — AI 시대 바이브 코더를 위한 웹 접근성 실전 가이드의
**실습 데모 사이트·예제 저장소**입니다.

Companion demos and examples for a Korean book on web accessibility for AI-assisted ("vibe coding") developers.

## 데모 사이트

- **https://demo.codeslog.com/book/vibe-a11y/**
- 책에서 다루는 접근성 문제를 브라우저에서 직접 겪어볼 수 있습니다 — 마우스를 치우고
  <kbd>Tab</kbd> 키로, 가능하면 스크린리더로도 써보세요.

## ⚠️ 일러두기 — 의도된 나쁜 예

이 저장소의 "나쁜 예(bad)" 페이지들은 접근성 문제를 체험하기 위해 **의도적으로 잘못 만든
교보재**입니다. 각 페이지 상단에 고지가 있으며, 실제 서비스에서 그대로 사용하면 안 됩니다.
좋은 예(good) 페이지와 데모 허브는 접근성 기준을 준수하도록 관리합니다.

## 구성

| 경로 | 내용 |
|---|---|
| `book/vibe-a11y/` | 데모 허브 — 장별 체험 페이지 목록 |
| `book/vibe-a11y/ch07/`, `ch08/` … | 장별 데모 (집필 진행에 따라 추가) |
| `book/vibe-a11y/rules/` | 복사해서 쓰는 접근성 규칙 세트 |
| `book/vibe-a11y/prompts/` | 본문의 "복사해서 쓰는 프롬프트" 모음 |
